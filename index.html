為日常瀏覽而設計

從外觀到搜尋，每個細節都可以依照你的習慣調整。

深色與淺色模式

自訂主題色，介面、首頁與錯誤頁會一起變換，還可以把分頁移到左側直排。

搜尋引擎任你選

支援 Google、DuckDuckGo、Bing 與 Yahoo，網址列與首頁搜尋都會使用你選擇的引擎。

首頁捷徑與問候語

常用網站可以設成首頁捷徑，每個捷徑都能設定顏色，問候語也能自己改寫。

本機檔案瀏覽

在網址列輸入 C: 或 D:，就能用簡潔的介面瀏覽磁碟與資料夾，並即時搜尋目前資料夾的檔案。

全螢幕與縮放

影片與網頁要求全螢幕時會自動進入，按 Esc 或 F11 離開；Ctrl+= 與 Ctrl+- 可以隨時縮放頁面。

三點選單與引導

所有功能都在三點選單中，第一次使用時還有六步的引導，介紹語言、分頁、個人化與全螢幕。

常見問題

我的瀏覽資料存在哪裡？

所有設定、書籤、歷史紀錄與網站資料都存在程式資料夾下的 data 資料夾中，不會上傳到任何伺服器。

Mochi Browser 會收集我的資料嗎？

Mochi Browser 本身沒有帳號系統，也不包含遙測功能。你使用的搜尋引擎與你造訪的網站，會依照其各自的隱私政策處理資料。

可以清除瀏覽紀錄嗎？

可以。在個人化選單中選擇「清除瀏覽資料」，也可以在「一般」設定中勾選關閉時自動清除瀏覽紀錄。

為什麼網頁無法複製貼上？

請確認焦點位於網址列或網頁內容中，並使用三點選單中的「編輯」功能。若仍有問題，歡迎到 GitHub 回報。
